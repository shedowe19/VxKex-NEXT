# Upstream source

This independent repository starts from the complete source tree of
[YuZhouRen86/VxKex-NEXT](https://github.com/YuZhouRen86/VxKex-NEXT),
commit `5df0008807f5b021625619093589b47710dbea38` (release 1.2.3.2465).

All 539 tracked upstream files, including import libraries, prebuilt DLLs,
debugging symbols, documentation and build utilities, were copied and
verified against their original Git blob hashes. Original author
attribution and file headers are preserved.

This is a standalone repository with its own history. The upstream
project's GitHub issues and release records were reviewed, not imported
as new GitHub issue objects or releases.

Subsequent changes are recorded as separate commits. Existing Chromium
sandbox compatibility behavior is retained unless explicitly changed.
